# 개인 회계장부 (Personal GL)

복식부기 원리로 동작하는 개인용 회계 앱입니다. SAP 같은 기업용 총계정원장(GL) 구조를 개인 가계에 맞게 줄였고, 휴대폰 홈 화면에 앱처럼 설치해 쓸 수 있습니다. 빌드 과정 없이 HTML 파일 하나로 동작합니다.

## 기능

| 화면 | 내용 |
|---|---|
| 대시보드 | 순자산과 월말 추이, 자산·부채·부채비율, 회계등식(자산 = 부채 + 자본) 검증, 월 수입·지출·순이익·저축률, 6개월 수입·지출 그래프, 지출 구성과 예산 대비 사용률, 계좌 잔액, 최근 전표 |
| 전표 | 간편 입력(지출·수입·이체)과 일반 분개(여러 줄 차변·대변). 차변 합계와 대변 합계가 같아야만 저장됩니다. 전표번호 자동 부여(연도-일련번호), 수정, 역분개, 삭제 |
| 원장 | 계정과목별 잔액, 계정별 총계정원장(전기이월, 상대계정·제좌, 잔액, 차기이월) |
| 보고서 | 재무상태표, 손익계산서(월·연 누적), 합계잔액시산표 |
| 설정 | 통화(KRW·SAR·USD·EUR·JPY), 계정과목표 추가·수정·숨기기, 비용 계정별 월 예산, 기초잔액(개시분개), JSON 백업·복원, 분개장 CSV 내보내기 |

### 회계 원리

- **복식부기와 대차평균의 원리.** 모든 거래는 차변과 대변에 같은 금액으로 기록되고, 맞지 않으면 저장되지 않습니다.
- **거래의 8요소.** 입력 화면이 줄마다 "비용의 발생", "부채의 증가"처럼 어떤 요소인지 보여 줍니다.
- **발생주의.** 카드로 쓴 날 비용이 잡히고, 카드값 결제는 부채 감소와 자산 감소로 처리돼 비용이 두 번 잡히지 않습니다.
- **자동 손익 대체.** 수익·비용은 기간별로 집계되고 재무상태표에서는 이익잉여금과 당기순이익으로 자본에 반영됩니다.
- 금액은 1/100 단위 정수로 저장해 소수점 오차가 생기지 않습니다.

## GitHub Pages로 배포하기

1. GitHub에서 새 저장소를 만듭니다(예: `ledger`). 공개 저장소여도 장부 데이터는 올라가지 않습니다.
2. 이 폴더의 파일 10개를 모두 저장소 루트에 올립니다(하위 폴더 없음). 휴대폰에서는 **Add file → Upload files**로 한 번에 여러 개를 고를 수 있습니다.
3. 저장소의 **Settings → Pages**에서 *Source*를 **Deploy from a branch**, 브랜치를 `main`, 폴더를 `/ (root)`로 정하고 저장합니다.
4. 1~2분 뒤 `https://<사용자명>.github.io/<저장소명>/` 주소가 열립니다.

### 휴대폰에 설치

- **iPhone (Safari):** 주소를 열고 공유 버튼 → **홈 화면에 추가**
- **Android (Chrome):** 주소를 열면 앱 안에 **설치** 버튼이 뜹니다. 안 보이면 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**

설치 후에는 인터넷 없이도 열립니다.

## 데이터는 어디에 저장되나요?

- **GitHub Pages 버전:** 장부는 그 휴대폰 브라우저의 저장소(localStorage)에만 있습니다. 서버나 GitHub로 전송되지 않습니다. 대신 다른 기기와 동기화되지 않고, 브라우저 데이터를 지우면 함께 지워지므로 **설정 → 백업 파일(JSON)** 을 정기적으로 받아 두세요. 백업 파일은 다른 기기에서 **백업 파일 불러오기**로 옮길 수 있습니다.
- **Claude 아티팩트 버전:** 같은 `index.html`을 Claude에서 열면 장부가 내 Claude 계정에 비공개로 저장되어 휴대폰과 PC에서 함께 보입니다.

두 버전 모두 백업 파일 형식이 같아서 서로 옮길 수 있습니다.

## 앱 수정 후 업데이트

`index.html`을 고친 뒤 `sw.js`의 `VERSION` 값을 올리면(`v1` → `v2`) 설치된 앱이 다음 실행 때 새 버전을 받습니다.

## 파일 구성

```
index.html             앱 전체 (HTML·CSS·JS 한 파일)
manifest.webmanifest   홈 화면 설치 정보
sw.js                  오프라인 캐시
icon.svg, icon-192.png, icon-512.png, maskable-512.png, apple-touch-icon.png   앱 아이콘 (T계정 모양)
```
